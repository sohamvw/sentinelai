# SentinelAI - Four selected India sector control packs

This runtime catalog is limited to the four user-selected sector packs. Each
scan selects exactly one of these packs; it does not apply unrelated sectors.

## RBI FinTech / Digital Payments

Source: RBI Master Directions on Cyber Resilience and Digital Payment Security
Controls for non-bank Payment System Operators, RBI/DPSS/2024-25/123, 30 July
2024. Applicability: authorised non-bank PSO or a system operated for one.
Key technical control domains: identity and least privilege, secure SDLC,
security testing, payment-data protection, API security, patching, incident
response, BCP/DR, cloud controls and audit logs.

## SEBI Stock Market / Securities

Source: SEBI Cybersecurity and Cyber Resilience Framework (CSCRF), Version
1.0, 20 August 2024. Applicability: SEBI Regulated Entities after entity and
RE-category assessment. Key domains: governance, asset/SBOM, access control,
secure SDLC, VAPT/revalidation, patching, logging, API security, incident
response and resilience testing.

## India E-Commerce

Source: Consumer Protection (E-Commerce) Rules, 2020 control pack supplied by
the user. Applicability: marketplace or inventory-model e-commerce systems
offering goods/services to Indian consumers. Key domains: grievance redressal,
affirmative purchase consent, return/refund/cancellation information and
consumer-data safeguards. Amendments must be added as versioned updates rather
than silently overwriting this source.

## India SaaS

Sources: CERT-In Directions under section 70B (2022), Digital Personal Data
Protection Act, 2023, and Digital Personal Data Protection Rules, 2025.
Applicability: CERT-In incident requirements as relevant to the entity; DPDP
controls only when the product processes digital personal data in scope.
Key domains: incident response, security logs, time synchronisation, contact
workflow, privacy notice, access control, safeguards, backup and breach
response. Organisational evidence such as retention operation, contracts and
reporting timestamps remains UNKNOWN unless evidence is supplied.
